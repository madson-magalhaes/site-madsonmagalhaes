# Versão Alternativa - Site de Consultoria em IA

## 🎨 Design Diferente

Esta é uma versão **alternativa** do site, com design mais **limpo e minimalista** inspirado em layouts modernos como o da Gabriela de Lima.

### Características da Versão Alternativa:

- **Tema Claro**: Fundo branco com texto escuro (oposto da versão principal)
- **Minimalista**: Design clean sem gradientes escuros
- **Orange como destaque**: Mantém a cor #FF6700 como principal
- **Tipografia simples**: Sistema de fontes padrão do navegador
- **Espaçamento generoso**: Mais ar e menos contenção
- **Cards leves**: Bordas sutis e sombras delicadas
- **Footer escuro**: Contraste apenas no rodapé

## 🚀 Rodar Localmente

```bash
cd versao_alternativa
npm install
npm run dev
```

Acesse: http://localhost:3000

- ✅ Target: Executivos e empresas mais conservadoras
